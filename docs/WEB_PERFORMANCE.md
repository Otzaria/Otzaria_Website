# מדידת ביצועי האתר

בדיקת GitHub Actions בשם `Web performance QA` בונה את האתר מול מסד נתונים מבודד ובו 93 תוספים לדוגמה. Chromium טוען את דף הבית, החנות, הקטלוג והכניסה לספרייה בהדמיית מובייל עם 400 Kbps בהורדה, 300 מילישניות השהיה והאטת מעבד פי ארבעה. הבדיקה שומרת LCP, זמן תגובה, נפח העברה ומספר בקשות לשרת כארטיפקט של הריצה. היא גם בודקת שהאנימציה אינה נדרשת בביקור האיטי ושהסינון המקומי בקטלוג מגיע לתוספים שנמצאים מעבר למנה הראשונה.

## תמונות ממוזערות לתוספים קיימים

בעת העלאת אייקון חדש נוצרת תמונה ממוזערת לכרטיס החנות. אחרי הפריסה אפשר להשלים תמונות קיימות באמצעות `node scripts/backfill-plugin-card-thumbnails.mjs [pluginId ...]` מתיקיית הגרסה הפעילה, באותה סביבת אחסון שבה האתר פועל. אפשר להתחיל בכמה תוספים בולטים. הפעלה ללא מזהים עוברת על כל תיקיות התוספים. הסקריפט משתמש ב־Sharp עם תהליכון אחד וממתין בין כתיבות. עד להשלמה, כרטיס עם אייקון קיים מציג את הקובץ הזמין.

## התקנת Brotli סטטי בפריסה

להפעלה, מגדירים במאגר הראשי שני משתני GitHub Actions. מגדירים את `OTZARIA_STATIC_BROTLI` לערך `true` ואת `OTZARIA_SSH_FINGERPRINT` לטביעת SHA256 של המפתח הציבורי של השרת. כל פריסה חדשה תייצר ב־CI גרסאות Brotli לקובצי JS ו־CSS של Next. בשלב האריזה, ה־VPS מעתיק רק גרסאות דחוסות שקובץ המקור שלהן זהה בבנייה המקומית. ההעתקה והאימות מתבצעים פעם אחת לפריסה. אם ארטיפקט חסר או שקובץ השתנה בין הבניות, הפריסה ממשיכה עם הקובץ הרגיל.

נדרשת הגדרה חד־פעמית מחוץ למאגר, בשרת nginx שבו מודול `ngx_http_brotli_static_module` זמין. האזור הבא מחליף את הטיפול בנתיב זה בלבד. יש למזג אותו עם כלל ה־nginx הקיים עבור נכסי Next אם כבר יש כזה.

```nginx
location ^~ /_next/static/chunks/ {
    alias /var/www/otzaria-web/.next/static/chunks/;
    brotli_static on;
    add_header Vary "Accept-Encoding" always;
    add_header Cache-Control "public, max-age=31536000, immutable";
    add_header X-Content-Type-Options "nosniff" always;
}
```

לפני טעינה מחדש מריצים `nginx -t`. אחרי הפריסה, בודקים על כתובת של קובץ תואם עם `curl -I -H 'Accept-Encoding: br' URL` שמתקבל `Content-Encoding: br`. בקשת `Accept-Encoding: identity` אמורה לקבל את אותו קובץ ללא דחיסה. פעילות gzip הקיימת נשארת זמינה ללקוחות שתומכים בה, בהתאם להגדרת שרת ה־nginx. כיבוי משתנה GitHub והסרת כלל ה־nginx משיבים את מסלול ההגשה הקודם.
