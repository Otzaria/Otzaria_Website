# התקנת מסלול תוספי השירות

המסלול כבוי כברירת מחדל. ההפעלה נעשית רק אחרי מעבר כל הסעיפים ב־`STAGING.he.md`.

## צד האתר

| משתנה | תפקיד |
|---|---|
| `SERVICE_PLUGINS_ENABLED` | `true` מדליק את המסלול. בלעדיו כל `/api/service-plugins/**` מחזיר 404, והממשק מוסתר |
| `SERVICE_PLUGIN_STORAGE_DIR` | תיקיית קבצי ההגשות. ברירת מחדל: `storage/service-plugins` בתיקיית האפליקציה. חייבת להיות מחוץ ל־`public` ולשרוד פריסה |
| `SERVICE_PLUGIN_WORKER_SECRET` | הסוד המשותף לאתר ולמתווך. לפחות 32 בתים אקראיים (`openssl rand -base64 48`). סוד חלש מכבה את API המתווך |

**MongoDB:** נדרש האינדקס הייחודי `service_port_owner` על `plugins.serviceState.reservedPortKeys`. יצירת טיוטה ממתינה לאתחול האינדקס; יש לוודא שהמשתמש של האתר רשאי ליצור אינדקסים. השריון מכסה הגשה פעילה ואת גרסאות השירות הנוכחית והקודמת. הניקוי השעתי משחרר שריונים שאינם נחוצים עוד.

**nginx:** ‏`client_max_body_size` חייב להתיר מתקין של 256 MiB בנתיבי `/api/service-plugins/`, וזמן הקריאה (`proxy_read_timeout`, `client_body_timeout`) צריך להספיק להעלאה איטית. ההגדרה הקיימת של האתר אינה בריפו; יש לבדוק אותה בשרת.

**ניקוי שעתי** (crontab של המשתמש שמריץ את האתר):

```cron
17 * * * * curl -fsS -X POST -H "Authorization: Bearer $CRON_SECRET" http://127.0.0.1:3000/api/cron/service-plugins-cleanup
```

**גיבוי וניטור:** תיקיית האחסון ואוסף `servicepluginreviews` נכללים בגיבוי. יש לנטר שטח פנוי; כשל כתיבה מחזיר 503 למפתח, לא קובץ חלקי.

**שבת:** שער השבת חוסם גם את API המתווך. המתווך ממתין ומנסה שוב; ההרשאה הקצובה של בדיקה שרצה פוקעת, והבדיקה ממשיכה אחרי השבת מהשלב השמור האחרון.

## המתווך

הקוד, יחידת systemd וטבלת ההגדרות המלאה: `workers/service-plugin-broker/README.he.md`. עיקרי הדרישות:

- משתמש מערכת ייעודי, בלי גישה לקבצי האתר ולסודות שלו מלבד `SERVICE_PLUGIN_WORKER_SECRET`.
- ClamAV עם מאגר חתימות מתעדכן (`freshclam`), ‏7-Zip, ‏GitHub CLI עם אסימון קריאה בלבד, ו־Claude Code.
- 7-Zip ו־ClamAV רצים בבידוד: בלי רשת ובלי הסוד (`SANDBOX_WRAPPER`). זה תנאי הפעלה.
- **`CLAUDE_AUTH_MODE` חובה ואין לו ברירת מחדל.** `api_key` משתמש במפתח API ובמצב `--bare`. `subscription` משתמש בהתחברות המנוי של משתמש המתווך. לפי עמוד התנאים של Claude Code, התחברות מנוי מיועדת לשימוש אישי רגיל, ושירות הפועל עבור אחרים צריך מפתח API. ההחלטה ובדיקתה מול התנאים הן של האחראי על הפריסה.
- VirusTotal כבוי עד שמוגדר `VT_API_KEY`, ורק אחרי אישור תנאי השימוש. גם אז הוא חל רק על הגשות שהמפתח הסכים בהן לשיתוף.

## סדר ההפעלה

1. פריסת האתר עם הדגל כבוי.
2. הגדרת הסוד, התיקייה, nginx וה־cron.
3. התקנת המתווך והפעלתו מול staging.
4. מעבר `STAGING.he.md`.
5. הדלקת `SERVICE_PLUGINS_ENABLED` בייצור.
