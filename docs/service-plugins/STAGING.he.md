# בדיקות קבלה לפני הפעלה

כל סעיף נבדק בסביבת staging עם MongoDB, ‏nginx והמתווך האמיתיים. סעיף שלא נבדק אינו מסומן כעבר, והדגל נשאר כבוי.

## העלאה והגשה

- [ ] תוסף חדש עם ״דורש שירות חיצוני״ מגיע לדף ההגשה, ולא מופיע ברשימת האישור הרגילה של המנהל.
- [ ] העלאת מתקין של 256 MiB עוברת דרך nginx בזרימה, בלי עלייה חדה בזיכרון של תהליך האתר.
- [ ] העלאה שנקטעה משאירה טיוטה שאפשר לבטל; קובץ שכבר נקלט אינו ניתן להחלפה.
- [ ] מתקין שהתוסף שבתוכו שונה מהתוסף העצמאי נדחה עם דוח ברור.
- [ ] פורט שכבר שייך לתוסף שירות אחר נחסם ביצירת ההגשה, גם בשתי הגשות מקבילות וגם כשהוא שייך לגרסת השירות הקודמת.
- [ ] בקשת כתיבה מ־Origin אחר נדחית.

## בדיקה ופרסום

- [ ] מתקין שנבנה ב־GitHub Actions עם אישור בנייה עובר את שלב האישור; מתקין בלי אישור, או מ־commit אחר, נדחה.
- [ ] מתקין NSIS, ‏MSI, ‏ZIP, ‏DMG, ‏PKG, ‏DEB, ‏RPM, ‏AppImage ו־APK לדוגמה נפתחים ב־7-Zip במכונת המתווך. Inno Setup ו־WiX Burn נדחים בהסבר.
- [ ] קובץ EICAR בתוך מתקין נחסם ב־ClamAV.
- [ ] ‏7-Zip ו־ClamAV רצים בלי רשת ובלי הסוד בסביבה (בדיקה בפועל, למשל ניסיון חיבור מתוך העטיפה).
- [ ] הרצת Claude אמיתית: אירוע ה־init מראה רק Read, ‏Grep ו־Glob ובלי שרתי MCP; הדוח בעברית ומתאר היקף, ממצאים ומגבלות.
- [ ] מקור עם הוראה לבודק בתוך קובץ מסומן בדוח כממצא.
- [ ] תוכן התוסף שהועלה נמצא ב-INDEX תחת `uploaded-plugin/` ונסקר גם כשהוא שונה ממקור GitHub, לרבות עדכון תוסף בלבד.
- [ ] שומר התקיעה: לוגים ב-stdout/stderr ללא אירועי פרוטוקול אינם מאפסים את השומר; סקירה ארוכה אמיתית אינה נעצרת. בודקים אם 10 דקות בלי אירוע מספיקות למודל, ומכוונים לפי הצורך.
- [ ] מיצוי מכסה (אמיתי או מדומה בקובץ CLI מזויף) משהה את כל התור עד מועד האיפוס ועוד דקה, ואינו דוחה את ההגשה.
- [ ] ניתוק המתווך אחרי שמירת קבלת Claude ממשיך בלי הרצה חוזרת של Claude.
- [ ] ביטול בזמן ריצה מונע פרסום מאוחר.
- [ ] אישור מפרסם אוטומטית; כשל מייל אינו מבטל את הפרסום.
- [ ] 21 יום: בדיקת שירות שנייה נחסמת; חריגת מנהל מאפשרת אחת ונצרכת. כשל כתיבה לפני הכנסה לתור ניתן לשחזור בניסיון חוזר, עם המועד והחריגה המקוריים.
- [ ] עדכון תוסף בלבד אינו כפוף ל־21 יום ונבדק בהקשר השירות המאושר.

## הורדה ואוצריא

- [ ] באתר: זיהוי שירות מקומי עובד ב־Chrome וב־Firefox, כולל בקשת ההרשאה לגישה מקומית; חסימתה משאירה בחירה ידנית.
- [ ] פרסום גרסה חדשה בזמן שחלון ההורדה פתוח אינו משנה את גרסת התוסף בהתקנה הישירה מהחלון.
- [ ] שירות תואם מציע את התוסף בלבד; לא תואם מציע עדכון; אין תשובה — שתי האפשרויות.
- [ ] מערכת לא נתמכת מוצגת מעומעמת; ארכיטקטורה נבחרת ידנית.
- [ ] חזרה לגרסה קודמת מחליפה את המתקינים ואת התוסף יחד, ואינה מאפסת 21 יום.
- [ ] מתקין שאינו נוכחי או קודם אינו ניתן להורדה, גם בקישור ישיר.
- [ ] עריכה ישירה, אישור ידני ומחיקת גרסה חסומים לתוסף שירות, גם למנהל וגם ל־GitHub Action של הוולידטור (409).
- [ ] אוצריא: בדיקת עדכונים מחזירה `requiresServiceCheck` לתוסף שירות ואינה מתקינה עדכון.
- [ ] `otzaria://plugin/install-local` ממתקין אמיתי עובד בכל פלטפורמה שמתקבלת. פלטפורמה שלא נבדקה אינה מתקבלת.
- [ ] תוסף החנות והמעדכן האופליין באוצריא תומכים בתוספי שירות — תנאי להפעלה לציבור.
