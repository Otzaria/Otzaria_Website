# תיקון ממצאי הביקורת החוזרת

בסיס: `f0c0c58`, ענף `feat/ocr-local-worker`, [PR 211](https://github.com/Otzaria/Otzaria_Website/pull/211).

**W10 תוקן:** רשימת התנגשויות ה־OCR מחזירה `nextCursor` לפי הצמד `(pageNumber, _id)`. בקשת ההמשך משתמשת ב־`after`, ולכן שינוי הסטטוס של שורות קודמות בידי מנהל אחר אינו מקדם את נקודת ההתחלה ואינו מסתיר עמודים שטרם נטענו. השרת מביא פריט נוסף כדי לקבוע `hasMore`. נשמרה תמיכה ב־offset ללקוחות ישנים, ונוסף אינדקס תואם. רשימות פתוחות שכבר נטענו אינן מנגנון עדכון חי; ניתן לרענן כדי לראות החלטות שנעשו בינתיים.

בדיקות רגרסיה כוללות UI עם 51 התנגשויות והכרעה מקבילה, API מול MongoDB עם הסרת שורה קודמת ועם הכרעת שורת העוגן, מיון לפי מזהה כשהעמודים שווים, ודחיית סמנים לא תקינים.

**S03/W09 תוקן בתיאום עם השירות:** תיעוד החוזה מגדיר 2,000,000 יחידות UTF-16 בדיוק, ומסביר מדוע `maxLength` של JSON Schema אינו מבטא אותה יחידה. בשירות נוספו אכיפה והמרת עמוד חורג לשגיאת `page_text_too_long` לפני הקפאה, תוך שמירת יתר העמודים. השינוי מצריך התקנת גרסת השירות המעודכנת; האתר ממשיך לדחות פלט חורג של לקוח ישן. בדיקת גבול חדשה עם אמוג'י מכסה זוגות surrogate.

האימות הבין־מערכתי הריץ `ResultFinalizer.Load` ו־`Commit` בשירות על עמוד בן 2,000,001 תווים, ואז בדק את הבתים שהוקפאו באמצעות `validateResult` באתר: **התקבלה תוצאת partial בת 396 בתים, עם שגיאת העמוד החורג ושמירת הטקסט של העמוד השני**.

אימות האתר: **2368 בדיקות Vitest עברו, 0 נכשלו, 0 דולגו**; 29 בדיקות UI/API ממוקדות עברו; **215 בדיקות Node של ה־OCR עברו ללא דילוגים**; TypeScript של מקורות המוצר ו־ESLint של הקבצים ששונו עברו.

ראיות מקומיות: `artifacts/recheck-round3/fixes-*.log` ו־`fixes-full.json`. בדיקת TypeScript משתמשת בהגדרת הביקורת שמחריגה את תיקיית artifacts, כי ניסוי ישן בתיקייה זו מייבא סיומת mts שאינה מותרת בהגדרת המוצר. לא שונתה הגדרת TypeScript של המוצר. לא בוצעו build ייצור חדש, פריסה או מסירה לשרת חי; כשל build חיצוני של plugin validator שתועד בסקירה הקודמת אינו מוכרז כאן כמתוקן.
